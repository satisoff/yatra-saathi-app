# Yatra Saathi

A free trip planner for Android. Tell it where you're going, when, with how many people and
how much you want to spend: it plans the train or bus there, a place to stay, each day's
sights with meals and local rides, and the way back, all inside your budget. Hindi and English.

## Install

1. On your Android phone (Android 7.0 or newer), download the latest APK:
   **[yatra-saathi.apk](https://github.com/satisoff/yatra-saathi-app/releases/latest/download/yatra-saathi.apk)**
2. Open the file. Android asks to allow installs from your browser or Files app; allow it once.
3. Newer versions install over the old one and keep your trips.

This repository only hosts the app's releases. All versions are listed under
[Releases](https://github.com/satisoff/yatra-saathi-app/releases).
